# Tråkk 0.3.20 — logo tilbake, mer plass til kartet

Android testutgave, versionCode 25. Installer som oppdatering uten å avinstallere.

Tråkk-logoen med ikon og ordmerke er tilbake i toppen av Utforsk, Turlogg og Deg. De store velkomstoverskriftene forblir fjernet.

«X av Y gater gått» vises bare under Deg. Kortet er fjernet fra Utforsk for å gi mer plass til kart og turstart. Telling, detaljliste og visning av gater på kartet er uendret. Tråkkvennen bærer fortsatt opptjent utstyr.
