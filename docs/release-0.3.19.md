# Tråkk 0.3.19 — logoen tilbake

Android testutgave, versionCode 24. Installer som oppdatering uten å avinstallere.

Den opprinnelige Tråkk-logoen med ikon og ordmerke er tilbake i toppen av Utforsk, Turlogg og Deg. De fjernede velkomstoverskriftene og forklaringstekstene forblir borte. Antrekk, fremgang og øvrig funksjonalitet fra 0.3.18 er uendret.

TypeScript og Android-bygg består. Logoen er gjeninnsatt med nøyaktig samme JSX som i 0.3.17. APK-versjon, Hermes og samme signatur som 0.3.18 er kontrollert. De fjernede velkomstoverskriftene er fortsatt borte fra APK-en. Fysisk telefon er ikke testet i byggmiljøet.
