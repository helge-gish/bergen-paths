# Tråkk 0.3.18 · Android-testutgave

Installer APK-en som **Oppdater**, uten å avinstallere. ARM64, versionCode 23, samme testsignatur som 0.3.17.

- Logoheader og velkomsttekster fjernet fra Utforsk, Turlogg og Deg.
- Tråkkvennen bærer opptjent caps, ryggsekk, turstav og gullmerke automatisk.
- Gatekortet viser «X av Y gater gått».

Kildecommit: `286747a`. Kildekodearkivet er eksportert direkte fra denne committen.
TypeScript, 200 app-/komponenttester og seks native tester består. Android-bygg og APK-signatur/bildeinnhold er kontrollert. Fysisk telefon er ikke testet i byggmiljøet.

`trakkvenn-utstyr.png` viser alle antrekkene, gjengitt med portrettkomponentens bildeutsnitt i nettleser.
