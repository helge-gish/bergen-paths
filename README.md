Tråkk er samlet i **Utforsk**, **Logg** og et tannhjul for **Innstillinger**.

- **Start/Pause:** Start-skjerm når registrering er av, med samtykke og tillatelser første gang. Pause lagrer målingene og stopper GPS/trening. Ingen kart-/AR-flyt før registrering er startet.
- **Utforsk:** turkart, Kamera/AR for naturstier, diskret treningsvalg og egne strekk. 4×4, japansk intervallgange og gå/jogg beholdes.
- **Logg:** «X av Y stier gått» i aktivt område, Innom/Gått-historikk, stitider og tidligere registreringer. Sammenhengende kartdeler grupperes.
- **Fast 5 km:** området festes der du er og kan flyttes i kartet fra Innstillinger. Over 25 km fra området stopper registreringen og ber om «Utforsk her» før et nytt område aktiveres.
- **Batteripause:** ti minutter med god, stillestående GPS stopper registreringen. Start kreves igjen etterpå. Aktiv treningsklokke unntas. Dårlig GPS alene utløser ikke batteripausen; manuell Pause er fortsatt nødvendig ved usikkert signal.
- **Profil:** vekt, kjønn og alder er valgfrie og lagres lokalt.
