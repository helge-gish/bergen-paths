Retter gjentatte Skredderdalen-oppføringer i turoppsummeringen.

- Sammenhengende kartdeler med samme navn vises som én oppføring, også når traseen veksler mellom sti og trapp. Samlingen bruker samme visning og teller steder med funn.
- Kartknappen viser alle delene. Samme trasé havner ikke i begge seksjonene av turoppsummeringen.
- Like navn på forskjellige steder holdes atskilt. Delvis gåtte traseer merkes med antall bekreftede deler, uten fullført-hake.
- Gjelder også tidligere turer når de åpnes igjen. Lagrede spor og kartbevis beholdes; ingen datamigrering eller ny kartnedlasting er nødvendig.

**Kontroll:** TypeScript og 154 JavaScript-tester består, inkludert seks nye regresjonstester. Android-releasebygget er fullført. Versjon og samme APK-signatur som 0.3.11 er kontrollert. Fysisk kontroll av denne visningen på telefon gjenstår.

Installer som **Oppdater**, uten å avinstallere eller tømme data. ARM64 · no.trakk.app · versionCode 17.

APK, SHA-256 og kildearkiv ligger i grenen trakk-apk-0.3.12. Kilden er bevart i taggen trakk-0.3.12 og grenen trakk-discovery-rows-0.3.12. Interne poeng-/milepælregler er ikke endret i denne visningsrettelsen.
