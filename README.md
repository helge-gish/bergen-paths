# Tråkk 0.3.22

GPS kan oppdateres mens brukeren står stille. Kompasset fortsetter gjennom varierende GPS-status. Kameraet viser tydelig klar-status og en fast nærhetsliste for stier og navngitte gater når retningen ikke er pålitelig. GPS og kamera har separate forsøk-knapper.

Installer som **Oppdater**, uten å avinstallere. ARM64, versionCode 27, samme testsignatur som tidligere utgaver.

Kildecommit: `41f8997`. TypeScript, 205 app-/komponenttester og Android-bygg består. APK-versjon, Hermes, nye tekster og signatur er kontrollert. Fysisk Pixel 6a er ikke tilgjengelig i byggmiljøet.
