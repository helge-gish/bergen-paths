Nye strekk får automatisk navn fra start, slutt og eventuelt et relevant sted underveis, for eksempel «Sandvikskirken – Fløyen via Skredderdalen».

- Brukes både når strekk markeres under turen og når et tidsrom lagres fra turloggen. Retningen følger GPS-sporet.
- Navnet i turloggens lagringsskjema følger tidsrommet du velger. «Endre» åpner navnefeltet hvis du ønsker et eget navn.
- «Via» tas bare med når GPS-sporet støtter passeringen. Samme trasé kan gi «Langs …», og samme start/slutt kan gi «Runde fra … via …».
- Manglende kartdata eller usikre posisjoner gir et enkelt standardnavn. Navngivingen bruker kartdata som allerede ligger på telefonen.
- Eksisterende strekk og egne navn omdøpes ikke automatisk. Ingen nye innstillinger.

**Kontroll:** TypeScript og 165 JavaScript-tester består. Android-releasebygget er fullført, med versjon og samme signatur som 0.3.12 kontrollert. Navneforslagene må fortsatt prøves på telefon med lokale kartdata.

Installer som **Oppdater**, uten å avinstallere eller tømme data. ARM64 · no.trakk.app · versionCode 18.

APK, SHA-256 og kildearkiv ligger i grenen trakk-apk-0.3.13. Kildekode: taggen trakk-0.3.13 og grenen trakk-stretch-names-0.3.13.
