# Tråkk 0.4.1

Installer trakk-0.4.1.apk som Oppdater, uten å avinstallere. Samme app og signeringssertifikat.

Nytt: japansk intervallgange (30 min) og gå/jogg (25 min), med tale, vibrasjon, pause og automatisk fritt tempo etterpå. 4×4 beholdes. Kart og AR beholder naturstifilteret.

249 app-/domenetester og 14 native tester består. Android-APK er bygget og signaturkontrollert. Ikke feltprøvd på telefon; Android kan fortsatt skjule låseskjermvarsler.

Kildekode: tag trakk-0.4.1 i helge-gish/bergen-paths. Vedlagt kildearkiv inneholder ikke SDK, avhengigheter eller signeringsnøkler.
