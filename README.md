# Tråkk 0.3.11

[Last ned APK](https://github.com/helge-gish/bergen-paths/raw/refs/heads/trakk-apk-0.3.11/trakk-0.3.11.apk)

Installer som **Oppdater** over 0.3.10, uten å avinstallere eller tømme appdata. ARM64 · versionCode 16 · samme signatur.

Låseskjerm med turklokke og målinger, vibrasjon ved 4×4-faseskifte, GPS med reserve fra siste posisjon, tydeligere strekk, navneforslag kun ved turslutt og færre valg/forklaringer i hovedflyten. Norsk talestemme velges automatisk; ingen stemme- eller dialektvelger.

148 JavaScript-tester, TypeScript og fire native Android-tester består. Fysisk felttest av denne versjonen gjenstår. Androids innstillinger styrer innhold på låseskjermen og vibrasjon.

[Kildekode](https://github.com/helge-gish/bergen-paths/tree/trakk-0.3.11) og kildearkiv ligger også på GitHub. SHA-256 for APK-en finnes ved siden av filen.
