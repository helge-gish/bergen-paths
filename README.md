# Tråkk 0.4.0 alfa

Android ARM64. Installer som oppdatering for å beholde turene.

Naturstier, automatisk registrering og stitider. 4×4 kan aktiveres underveis og gjentas uten å stoppe GPS. En bevisst GPS-pause varer til Fortsett.

Kildecommit: `0bc893fb58d59f478caf7716ca13288b4abbcb35`.

244 tester og TypeScript består. Android-bygg og 14 native tester består. Samme signatur; ingen fysisk telefon tilkoblet. Denne større endringen i arbeidsflyten må feltprøves.
