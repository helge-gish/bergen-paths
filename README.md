# Tråkk 0.3.10 – Android-testversjon

[Last ned APK](https://github.com/helge-gish/bergen-paths/raw/refs/heads/trakk-apk-0.3.10/trakk-0.3.10.apk)

Installer som **Oppdater** over 0.3.9. Ikke avinstaller eller tøm appdata. APK-en er for ARM64 og har samme signatur som 0.3.9. Android-versjonskode: 15.

Denne grenen oppbevarer nedlastingsfilene fordi GitHubs release-opplasting svarte 401. Kildekoden ligger i taggen [trakk-0.3.10](https://github.com/helge-gish/bergen-paths/tree/trakk-0.3.10) og i `trakk-0.3.10-source.zip` her.

TypeScript, 141 tester og Android-releasebygget består. APK-signatur, pakkenavn, versjon og innebygd Hermes-kode er kontrollert. Test på fysisk telefon gjenstår.
