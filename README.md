# Herebound 0.3.1 – funn på Meyermarken

[Last ned APK](https://github.com/helge-gish/bergen-paths/raw/refs/heads/herebound-apk-0.3.1/herebound-0.3.1.apk). Installer som **Oppdater**, uten å avinstallere.

Alle fem ULTIMA X-møtene er samlet innen omtrent 15 meter fra det eksisterende testsenteret på Meyermarken (60.40418, 5.32703): tursekken, rognebærene, Maren, Rusk og lykten. Det gjør AR-prøven enklere uten å måtte oppsøke de tidligere plasseringene mellom bygningene. Faktisk tilgjengelighet og plassering må bekreftes på stedet.

Start ute fra Meyermarken, åpne Kart / Kamera · AR og velg et funn. Fersk GPS og AR-møte kreves fortsatt for feltinteraksjon. Prøvemodus kan brukes hjemme. Startsonen, avatarverksted, XP, utstyr og skins fra 0.3.0 beholdes.

Spillpakken beholder versjon 1 og alle møte-ID-er. Eksisterende progresjon og inventar beholdes; allerede fullførte funn blir ikke fylt på av oppdateringen. Historieforslaget «Meyers hemmelighet» er dokumentert som en idé og er ikke innført i spillet. Isdalskvinnen er notert som et mulig senere separat spill.

Kontroll: 326 tester i fellesprosjektet og TypeScript-kontroll består, inkludert plasseringer, bevart pakkekontrakt og avvisning av handlinger utenfor rekkevidde. Android-bygg består; APK-kontrollen bekrefter versjon 0.3.1 (kode 5), app-ID no.herebound.app, AR-moduler og samme testsignatur som tidligere. Ingen fysisk AR-test er utført her; prøv helst første plasseringsrunde i dagslys.
