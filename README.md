# Tråkk 0.3.17 · testutgave

[Last ned APK](https://github.com/helge-gish/bergen-paths/raw/refs/heads/trakk-apk-0.3.17/trakk-0.3.17.apk) · [Kildekodearkiv](https://github.com/helge-gish/bergen-paths/raw/refs/heads/trakk-apk-0.3.17/trakk-0.3.17-source.zip)

Installer som **Oppdater**, uten å avinstallere. ARM64 Android, versionCode 22, samme testsignatur som 0.3.16.

- **Gater i nærområdet:** fremtredende teller i Utforsk før turstart og øverst under Deg. Viser fullførte gater, andel av kartlagte gater og antall delvis gått. Trykk for liste og visning av gatene på kartet.
- **Ærlig progresjon:** tellingen bruker valgt radius og eksisterende GPS-bevis. Uferdig sjekk, manglende kartgrunnlag og sist kjente posisjon merkes. Delvis gått gir ikke full uttelling; pågående tur teller etter lagring.
- **Tråkkvennen:** ny vennlig figur med regnjakke og tursko erstatter fantasygrafikken. Mann/dame-valg og opptjent XP beholdes. Rolig animasjon følger innstillingen for redusert bevegelse.
- **Utstyr:** samlingen viser tursko, caps, ryggsekk, turstav og merke med nivåkrav. Påkledning og figurbygger er planlagt for v2, sammen med frivillig sosial spillmodus og lokale utfordringer.

TypeScript og 198 app-/komponenttester består. Rent Android-appbygg og seks native tester består. Signatur, nye tekster, nytt bildeinnhold og fravær av det gamle fantasybildet er kontrollert. Fysisk telefon er ikke tilgjengelig i byggmiljøet.

Gatemålingen gjelder navngitte gater i hentede kartdata, ikke nødvendigvis alle gater som finnes. Appens eksisterende fullføringsregler er beholdt. Sosiale funksjoner og synlighet for andre er ikke aktivert.
